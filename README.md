# SCSS Color Preview Local

Local VS Code extension for inline color swatches on:
- SCSS variables like `$primary-500`
- CSS custom properties like `--tone`
- derived expressions such as `color.mix(...)`, `tint(...)`, `shade(...)`, `var(--tone)`, `#{$primary-500}`

## Run locally
1. Open this folder directly in VS Code.
2. Press `F5` and choose `Run Extension`.
3. In the Extension Development Host, open a project with `.scss` or `.css` files.
4. Run `SCSS Color Preview: Refresh` if needed.
